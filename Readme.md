# SOAR-GS

**Semantically Guided Active Scene Reconstruction Using Gaussian Splatting and Class-Level Geometric Complexity**

The manuscript is currently under review. This repository will host the source code and documentation for SOAR-GS.

Before the public release, we will complete code cleanup and prepare documentation covering software dependencies, experiment configurations, and evaluation procedures. These preparations will help other researchers set up the software and reproduce the reported experiments.

We plan to release the source code and documentation by the end of 2026.
